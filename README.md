# Python TCP 聊天室（ChatRoom）

基于 Python 标准库 `socket` 和 `threading` 实现的简单局域网聊天室。项目来自《计算机网络及安全》课程大作业，由两人协作开发。

> 当前版本为命令行原型：已完成跨设备通信、多人群聊和双向私聊的基础测试；图形化界面仍在开发中。

## 功能

- **TCP 通信**：客户端连接服务器，使用 UTF-8 传输中文消息。
- **多人群聊**：服务器通过多线程处理连接，并向其他在线客户端广播消息。
- **用户登录**：使用用户名登记在线连接。
- **指定用户私聊**：使用 `@用户名 消息` 发送私聊；找不到用户时返回提示。
- **按行解析消息**：服务器以换行符 `\n` 区分消息，缓冲不完整的数据。

## 技术栈

Python 3、Socket、TCP、threading（仅使用标准库，无额外依赖）。

## 运行方法

1. 在服务器电脑运行：
   ```bash
   python server.py
   ```
2. 在客户端文件 `client2.py` 中，将 `SERVER_IP` 改为运行服务器的电脑的 **IPv4 地址**（例如 `192.168.1.10`）。默认端口是 `8888`。
3. 在能访问该服务器的电脑上运行：
   ```bash
   python client2.py
   ```
4. 输入用户名。打开两个及以上客户端，就可以测试群聊和私聊。

| 客户端输入 | 作用 |
| --- | --- |
| `大家好` | 发给其他在线客户端 |
| `@小明 你好呀` | 私聊用户“小明” |
| `exit` | 结束客户端输入循环 |

同一台电脑测试时，可以把 `SERVER_IP` 设置为 `127.0.0.1`。跨设备测试时需保证网络互通，必要时检查防火墙。

## 通信协议

消息使用 UTF-8 编码，并以换行符结束：

```text
LOGIN|用户名\n
GROUP|发送者|内容\n
PRIVATE|发送者|接收者|内容\n
```

服务器转发的私聊格式为 `PRIVATE|发送者|内容\n`；目标用户不在线时返回 `ERROR|提示\n`。
