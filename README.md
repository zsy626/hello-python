# ChatRoom · Python TCP 局域网聊天室

双人合作完成的《计算机网络及安全》课程实践项目。使用 Python Socket 与 TCP 实现多人聊天，并使用 Tkinter 制作图形界面。

**项目进展：** 已在两台电脑上测试基础群聊、双向私聊、在线用户列表和下线通知。课程实验报告正在整理中。

## 功能

- **多人群聊**：服务器通过线程分别处理多个客户端，消息转发给其他在线用户。
- **定向私聊**：输入 `@用户名 消息`，向指定在线用户发送消息。
- **昵称登录**：服务器登记在线用户，拒绝重复昵称。
- **在线用户列表**：用户上线、下线时向客户端发送更新后的名单。
- **上线/下线管理**：服务器记录登录与断开；下线时通知其他用户。
- **中文通信**：UTF-8 编码，消息以换行符分隔；服务端与新版图形客户端均使用缓冲区按行解析 TCP 数据。
- **图形界面**：Tkinter 聊天窗口、昵称输入、消息输入、发送按钮和消息展示。

## 技术栈

- Python 3
- `socket`：TCP 网络通信
- `threading`：并发处理连接、客户端后台接收
- `tkinter`：桌面图形界面

## 通信协议

以 UTF-8 编码，每条消息以 `\n` 结束。

| 消息格式 | 用途 |
| --- | --- |
| `LOGIN\|小红\n` | 登录昵称 |
| `GROUP\|小红\|大家好\n` | 发送群聊 |
| `PRIVATE\|小红\|小明\|你好\n` | 发送私聊 |
| `USERS\|小红\|小明\n` | 服务器推送在线用户 |
| `NOTICE\|小红已下线\n` | 服务器推送下线通知 |
| `ERROR\|提示内容\n` | 服务器返回错误 |

服务器转发给私聊接收者的格式为 `PRIVATE|发送者|消息内容\n`。

## 运行方式

1. 在服务器电脑运行 `python server.py`（监听 `0.0.0.0:8888`）。
2. 修改 `gui_client.py` 的 `SERVER_IP` 为服务器电脑的 IPv4 地址；同机测试可使用 `127.0.0.1`。
3. 在能访问服务器的电脑上运行 `python gui_client.py`，输入不同昵称登录。
4. 直接输入文字发送群聊，或输入 `@用户名 消息` 发送私聊。

**文件说明：** `server.py` 是服务器端；`gui_client.py` 是 Tkinter 图形客户端；`client2.py` 保留早期命令行客户端，供学习和调试。
